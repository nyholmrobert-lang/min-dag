# Min dag

Pilot för ett enkelt, visuellt dagschema på iPad för ett barn som ännu inte läser flytande.

- Visar **Nu** och **Sedan** med stora symboler, en grön "Klar"-knapp och en timer som krymper.
- En stjärna för varje avklarad aktivitet.
- Föräldravy (låst med en multiplikationsfråga) för tider, aktiviteter, symboler och vilka knappar barnet ser.
- Allt sparas lokalt i webbläsaren på enheten. Inget skickas någonstans. Säkerhetskopia finns i föräldravyn.

Öppna sidan på iPaden i Safari och välj Dela → Lägg till på hemskärmen.

Status: pilot under test.
